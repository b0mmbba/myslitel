# Мыслитель MVP 0.4

Android-прототип: чат с ИИ, нижняя плавающая панель, ручной анализ текущего экрана и осторожный Live-режим.

Live-режим не управляет телефоном. Он делает один кадр примерно раз в 12 секунд и отправляет его в OpenAI API для короткого комментария.

Важно: API key хранится локально только для личного тестового MVP. Для публичной версии нужен сервер-прокси.
