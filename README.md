# Мыслитель MVP 0.1

Это первый прототип Android-приложения “Мыслитель”.

Что умеет сейчас:
- хранит OpenAI API key локально на телефоне;
- отправляет текстовый запрос в OpenAI Responses API;
- показывает ответ в простом чате.

Что будет дальше:
- нижняя плавающая панель поверх экрана;
- запрос разрешения на просмотр экрана;
- отправка скриншотов в модель;
- live-комментарии по экрану.

## Как собрать APK через GitHub с телефона

1. Создай новый репозиторий на GitHub, например `myslitel`.
2. Загрузи все файлы из этой папки в репозиторий.
3. Открой вкладку `Actions`.
4. Запусти workflow `Build debug APK`, если он не стартовал сам.
5. После сборки открой завершённый запуск и скачай artifact `myslitel-debug-apk`.
6. Внутри будет `app-debug.apk`.
7. Установи APK на телефон. Возможно, Android попросит разрешить установку из неизвестных источников.

## Важно про безопасность

В этом MVP API ключ хранится прямо на телефоне. Для личного теста это нормально, но для публичного приложения так нельзя. В публичной версии нужен свой backend/proxy, чтобы пользователи не видели ключи и чтобы можно было ограничивать расходы.
