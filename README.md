# Мыслитель MVP 0.3

Android-прототип экранного AI-помощника.

Что есть в версии 0.3:

- чат с OpenAI API;
- сохранение API key локально на телефоне;
- нижняя плавающая панель поверх других приложений;
- ручной анализ текущего экрана через MediaProjection;
- кнопка “Анализ” прямо на нижней панели.

Важно: это всё ещё прототип. В 0.3 нет управления телефоном и нет постоянного live-режима. Приложение отправляет один сжатый кадр только после нажатия кнопки анализа.

## Как тестировать

1. Установи APK поверх старой версии или удали старую и установи заново.
2. Открой “Мыслитель 0.3”.
3. Убедись, что API key сохранён.
4. Нажми “1. Разрешить панель поверх экрана”.
5. Нажми “2. Включить нижнюю панель”.
6. Нажми “3. Разрешить просмотр экрана” и подтверди системный запрос Android.
7. Сверни приложение, открой любой экран.
8. Нажми “Анализ” на нижней панели.
