# Мыслитель MVP 0.7

Android-прототип экранного AI-помощника.

## Что есть в 0.7

- Чат с OpenAI API.
- Нижняя overlay-панель поверх других приложений.
- Ручной анализ текущего экрана.
- Live-комментарии.
- Режимы работы: Комментатор, Навигатор, Учитель, Антиошибка, Тихий.
- Контекст сессии и локальная оценка расхода API.
- Панель очищена: без служебных надписей и кнопок ↑/↓.
- Управление телефоном через Accessibility:
  - Автошаг — ИИ выполняет одно действие.
  - Автопилот — ИИ делает осторожные шаги по задаче пользователя.
  - Доступные действия: tap, swipe, scroll_up, scroll_down, type, back, home, none.

## Безопасность

Автопилот не надо запускать на банках, платежах, паролях, 2FA, личных переписках и удалении данных. В промпте модели заложена блокировка опасных экранов, но это не гарантия. Для остановки используй кнопку “Стоп авто”.

## Сборка

Проект собирается через GitHub Actions. После push открой Actions, дождись зелёной галочки, скачай artifact `myslitel-debug-apk` и установи `app-debug.apk`.
