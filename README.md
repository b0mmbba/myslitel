# Мыслитель MVP 0.5

Android-прототип, собранный с телефона через GitHub Actions.

## Что умеет 0.5

- обычный чат с OpenAI API;
- нижняя overlay-панель поверх других приложений;
- ручной анализ текущего экрана;
- осторожный live-режим с анализом примерно раз в 12 секунд;
- остановка просмотра экрана, чтобы вернуть обычные скриншоты;
- поле сообщения прямо на нижней панели;
- режимы работы: Комментатор, Навигатор, Учитель, Антиошибка, Тихий;
- контекст сессии: пользователь может сохранить цель/задачу, а модель будет учитывать её при анализе.

## Важно

Это всё ещё прототип. Он не управляет телефоном и не нажимает кнопки. Он только смотрит разрешённый экран и пишет комментарии.

API-ключ хранится локально на телефоне только для MVP. Для публичной версии нужен сервер-прокси.
