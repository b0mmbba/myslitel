# Мыслитель MVP 0.3.1

Android-прототип с:

- текстовым чатом через OpenAI API;
- нижней панелью поверх других приложений;
- ручным анализом одного кадра экрана по кнопке «Анализ»;
- исправлением запуска MediaProjection на Android 14+: просмотр экрана теперь запускается через foreground service с типом `mediaProjection`.

Важно: это личный MVP. API-ключ хранится локально на телефоне только для теста. Для публичной версии нужен сервер-прокси.
