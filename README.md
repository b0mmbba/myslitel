# Мыслитель MVP 0.7.3

Версия 0.7.3 улучшает автопилот:

- после каждого действия автопилот ждёт паузу, делает новый скрин и только потом выбирает следующий шаг;
- добавлен action `tap_sequence` для игр и шахмат: несколько тапов подряд, например выбрать фигуру и клетку;
- увеличен лимит шагов автопилота до 18;
- ответы управления стали длиннее, чтобы JSON реже обрезался;
- если модель не вернула JSON, автопилот не останавливается сразу, а пробует повторить;
- для шахмат добавлен аварийный тестовый ход e2→e4, если модель вернула пустой ответ.

Важно: автопилот всё ещё экспериментальный. Не использовать на банках, паролях, платежах, 2FA, удалении данных и личных переписках.
