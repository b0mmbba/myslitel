# Мыслитель MVP 0.7.2

Исправление автопилота: после каждого действия приложение ждёт небольшую паузу, делает новый скриншот и только потом выбирает следующий шаг. Добавлен прямой запуск установленного приложения по названию, улучшены повторные попытки, если модель вернула пустой ответ или не-JSON.

Главные возможности:
- нижняя overlay-панель: чат, Анализ, Live, Стоп, Автошаг, Авто, Стоп авто;
- просмотр экрана через MediaProjection;
- управление телефоном через AccessibilityService;
- автопилот с новым скрином после каждого действия;
- безопасные блокировки для платежей, паролей, банков и опасных действий.
