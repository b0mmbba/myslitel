# Мыслитель MVP 0.2

Android-прототип экранного AI-помощника.

## Что умеет версия 0.2

- сохраняет OpenAI API key локально на телефоне;
- отправляет текстовые вопросы в OpenAI Responses API;
- показывает ответы в приложении;
- запрашивает разрешение Android “Показывать поверх других приложений”;
- включает нижнюю плавающую панель поверх других приложений.

## Чего ещё нет

- нет просмотра экрана;
- нет live-комментариев;
- нет управления телефоном;
- API key пока хранится локально в приложении — для публичной версии нужен сервер-прокси.
