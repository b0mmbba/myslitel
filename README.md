# Мыслитель MVP 0.6.2

Android-прототип экранного AI-комментатора.

## Что есть в 0.6.2

- Текстовый чат с OpenAI API.
- Ручной анализ текущего экрана по кнопке.
- Осторожный live-режим: анализ примерно раз в 12 секунд.
- Режимы работы: Комментатор, Навигатор, Учитель, Антиошибка, Тихий.
- Режимы теперь описаны в приложении: это разные инструкции к одной модели, а не разные модели.
- Нижняя overlay-панель упрощена: поле чата + Спросить + Анализ + Live + Стоп live.
- Остальные кнопки оставлены в основном приложении.
- Панель можно двигать вверх/вниз за верхнюю строку или кнопками ↑/↓ на самой панели.
- Добавлена кнопка сброса просмотра экрана и повторного запроса разрешения.
- Добавлен локальный счётчик бюджета API.

## Модель

В коде используется модель:

```text
gpt-5.5
```

## Важно про баланс API

Приложение показывает не официальный баланс OpenAI, а локальную оценку: пользователь задаёт бюджет и цены за 1M input/output tokens, приложение читает usage из ответов API и примерно считает расход.

Официальные usage/costs endpoints требуют Admin API key. В мобильный APK такой ключ лучше не вставлять.

## Безопасность

Не тестировать на банках, паролях, кодах 2FA, приватных чатах и экранах с API-ключами.
